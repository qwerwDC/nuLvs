# NULV · NulvTeam

Статический фан-сайт клана в Standoff 2. Весь сайт работает на HTML, CSS и JavaScript. Сборка, npm, сервер и API-ключи не требуются.

## Посмотреть на Mac

Распакуйте архив и откройте `nulv-clan/index.html` двойным щелчком. Файлы и папку `assets` оставьте рядом с `index.html`. Избранное хранится только в браузере; доступность локального хранения и копирования ID при открытии файла зависит от браузера. На опубликованном HTTPS-сайте эти функции доступны нормально.

## Опубликовать на GitHub Pages

1. Создайте публичный репозиторий, например `nulv-clan`.
2. Откройте **Add file → Upload files**.
3. Перетащите **содержимое** папки `nulv-clan`, а не саму внешнюю папку и не ZIP. В корне репозитория должны оказаться `index.html`, `style.css`, `app.js`, `data.js`, папки `assets` и `downloads`. Комплект аватарок лежит в одном небольшом архиве внутри папки downloads. Файл `.nojekyll` также можно загрузить; сайт не использует шаблоны Jekyll.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**. Выберите **Deploy from a branch**, затем **main**, папку **/(root)** и **Save**.
6. После успешной публикации GitHub покажет адрес сайта. Обычно для такого репозитория он имеет вид `https://ВАШ-ЛОГИН.github.io/nulv-clan/`.

Если публикуете через Git, загрузите те же файлы в корень репозитория. Абсолютных путей вида `/assets/...` в коде нет: сайт рассчитан на адрес с названием репозитория.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Что работает

- Обзор клана и состав из 15 участников со скриншотов.
- Поиск по нику и игровому ID, сортировка, избранное на этом устройстве.
- Личная карточка каждого участника, переходы между карточками.
- Переключение оригинальной и улучшенной аватарки. Оригинал показывается из соответствующего участка исходного скриншота, без перерисовки.
- Скачивание отдельной аватарки и всего комплекта одним архивом, копирование ID.
- Галерея четырёх созданных для сайта игровых иллюстраций, полноразмерный просмотр и скачивание.
- Большой логотип клана и его скачивание.
- Адаптивные стили для компьютеров и телефонов, управление диалогами с клавиатуры, учёт уменьшенной анимации.

## Как менять состав

Откройте `data.js`. Каждый объект в `players` — один участник. Поля:

```js
{slug:'saev', name:'saev', id:'154006088', leader:true,
 style:'Фиолетовая энергия', note:'Описание оформления аватарки',
 source:1, crop:[509,314,78,78]}
```

- `slug` — имя файла аватарки в `assets/avatars`, без `.webp`.
- `name` и `id` — публичные игровые данные.
- `leader` — подпись лидера; у остальных поле можно не указывать.
- `style` и `note` описывают изображение, а не игровые способности участника.
- `source` и `crop` указывают исходный скриншот и прямоугольник оригинальной аватарки для сравнения: `[x, y, ширина, высота]`.

Для нового участника добавьте WebP в `assets/avatars`, внесите объект в `players` и обновите архивы в `downloads`. Дата актуальности задаётся в `updated`. Число в составе вычисляется из списка. Игровые статусы не обновляются автоматически: сайт не подключён к серверам игры.

Игрок с ником `weird` исключается из массива при загрузке. На присланных скриншотах отдельный ник `weird` не обнаружен. Если это новое имя одного из участников, удалите соответствующий объект по игровому ID.

Сложные декоративные символы в никах перенесены вручную. Перед публикацией сверьте их с игровым профилем; обычные ники и ID перенесены со скриншотов. Обозначение лидера у saev основано на значке в первой строке состава.

## Изображения

Облегчённая версия: изображения сохранены в WebP с высоким качеством. Разрешение сохранено, содержимое и кадрирование не менялись. Это уменьшает размер скачивания и ускоряет загрузку сайта.

`assets/avatars` — улучшенные версии аватарок участников. Это восстановление/художественное улучшение по маленьким изображениям со скриншотов, а не извлечение исходных файлов игры: мелкие детали могут отличаться. Узнаваемые персонажи и основные цвета сохранены.

`assets/logo.webp` — восстановленный логотип. `assets/art` — четыре оригинальных игровых фан-арта; они не являются скриншотами Standoff 2 и не изображают реальных участников команды. Все файлы лежат в архиве, внешние фотосервисы не нужны.

Изображения подготовлены встроенным инструментом генерации и редактирования изображений. Промпты/описания заданий сохранены в `ASSET_PROMPTS.md`.

## Проверки

Проверен синтаксис JavaScript и функциональные сценарии DOM: все карточки, сравнение, поиск, избранное, переключение игроков, копирование ID, галерея и пути к файлам. Изображения просмотрены. Полноценная визуальная проверка сайта в браузере и публикация в вашем GitHub ещё не выполнялись.

Для быстрой проверки после публикации откройте карточку участника, сравните изображения, скачайте аватарку, скопируйте ID и попробуйте поиск на телефоне.
